# Лендинг эксперта

Публичная страница Persona1ia на React, TypeScript и Vite. Содержимое приходит из сервера и редактируется в соседней [админке](../admin/README.md).

## Запуск

Нужен Node.js 24. Сначала запустите [сервер](../server/README.md) на порту 3000, затем в этом репозитории:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Запросы `/api` автоматически передаются серверу. Создайте блоки и курсы в админке, нажмите «Опубликовать» и обновите лендинг.

## Что работает

- Все восемь типов блоков: главный экран, об эксперте, текст, курсы, галерея, отзывы, вопросы и контакты.
- Порядок блоков и курсов, изображения, ссылки и видимость соответствуют опубликованным настройкам.
- «Записаться» открывает контакты эксперта; письмо получает тему с названием курса. Если контактов нет, запись недоступна. Оплата, CRM и создание заказов не подключены.
- Мобильная версия, навигация по разделам, управление с клавиатуры, состояния загрузки, ошибки и пустой страницы.

Тексты выводятся как обычный текст. Название вкладки и описание страницы берутся из настроек. Демо-данных нет. Контакты из настроек публичны и доступны для записи даже без отдельного блока «Контакты».

## Проверки и сборка

```sh
npm test
npm run build
```

Тесты проверяют все типы блоков, скрытие и порядок, контакты, цены, безопасные ссылки и ошибки API. Сборка включает проверку TypeScript и создаёт `dist`.

## Развёртывание

Разместите `dist` в корне сайта, админку — в `/admin/`, API — в `/api/` на том же HTTPS-домене. Пример прокси и настройка постоянной базы есть в [README сервера](../server/README.md). Не направляйте `/api/` на HTML лендинга. Для публикации изменений содержимого пересборка не нужна.

Лендинг загружает данные в браузере; серверный рендеринг и отдельные страницы курсов пока не предусмотрены.
